# Overlap correlates with recall error

## Abstract
We examine high-dimensional vector representations across associative memory networks. Through extensive observational logging of sequential retrieval tasks, we demonstrate a strong statistical correlation between representational subspace overlap and catastrophic interference during sequential weight updates.

## 1. Associative Interference in High Dimensions
When distributed representations share overlapping non-zero dimensions, gradient descent updates applied to newly presented items perturb synaptic weights that encode previously stored memories.

Across 10,000 simulated associative recall trials, Pearson correlation between cosine similarity of memory vectors and recall degradation was r = 0.84 (p < 0.001).
